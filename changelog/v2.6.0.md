# Outlet Radar v2.6.0 — Impact partner catalogs in Compare

## What it adds
- **Compare offers** now searches the product catalogs of every advertiser that has approved your Impact publisher account (for example adidas, New Balance, Puma, Reebok, Vans, Converse, Foot Locker, Finish Line, Macy's, if you have joined their programs) and shows offers that match the exact product.
- Each Impact item already carries your **affiliate tracking link**, so these offers can earn commission. When Impact and Channel3 both return the same store, the Impact offer (with the tracking link) replaces Channel3's plain link.
- Advertiser names come from your Impact catalog list; the cheapest matching item per store is shown, with the feed's in-stock or out-of-stock signal (never a size-level claim).
- Matching is the same strict model matching as the other live sources: every model word and the same model numbers, so other colorways and models are excluded.
- Live only: cached for 3 hours, never saved to the normalized catalog, and an incomplete result (budget reached, paused, error) is not cached.
- App ceiling `IMPACT_DAILY_BUDGET` 500 and `IMPACT_MONTHLY_BUDGET` 15,000 calls (Impact does not publish a fixed free quota; adjust to what your account allows). One call per Compare, plus one catalog-name lookup per six hours.

## What it does not do
- It only finds stores that have **approved your account**. Joining more brand programs in Impact (adidas, New Balance, Puma, and so on) is what widens coverage.
- It is a live search, not a bulk download of feeds into Neon. That keeps storage within Neon's free 0.5 GB and avoids keeping affiliate data longer than needed.

## Migration and configuration
- No database migration.
- New optional variables: `IMPACT_ACCOUNT_SID`, `IMPACT_AUTH_TOKEN`, `IMPACT_DAILY_BUDGET`, `IMPACT_MONTHLY_BUDGET`.

## Validation
- Production build and TypeScript check pass.
- 71 scenario checks pass against PostgreSQL with mocked providers, including: Basic auth and JSON request, the AND-ed name query, exact-product filtering, advertiser-name lookup, cheapest per store, tracking links, out-of-stock signal, Channel3 de-duplication, error and budget handling, and no catalog persistence.
- Not exercised against the live Impact API. The endpoint, authentication and response fields follow Impact's published partner API reference, but the name-query syntax (`Name~'word' AND ...`) was not confirmed against a live account. If a Compare shows an Impact error status, the message includes Impact's own response; send it to me and I will adjust the query.
