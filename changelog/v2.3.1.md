# Outlet Radar v2.3.1 — Retailer coverage report

- `/admin/providers` now has a **Retailer coverage** section. It compares the sellers actually stored in `retailer_offers` (from real searches) against a target list: StockX, GOAT, Flight Club, Kicks Crew, Nike, Foot Locker, JD Sports, Jimmy Jazz, Champs Sports, Finish Line, Snipes USA, Macy's, Bloomingdale's and eBay. Each shows offers, products and last seen, or "not seen yet", plus any other sellers found.
- The target list lives in `lib/retailer-targets.ts` and is for reporting only; it never filters or changes search results.
- No migration or new environment variable.
