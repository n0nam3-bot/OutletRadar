# Outlet Radar v1.9

- Replaced the Nike-led home page with a single retailer-neutral “What are you hunting for?” discovery experience.
- Removed the separate Nike search interface from the visible home page; product discovery now searches supported catalogs across brands.
- Removed the old Nike-directory outbound navigation. The Stores section is now an in-app nearby retailer locator with address and directions links.
- Kept the first screen compact by removing the large hero artwork and keeping advanced refinements collapsed behind a clearly labeled Filters control.
- Added local catalog refinements for audience/gender, size, color, minimum and maximum price, and sale-only. Refinement changes reuse the same cached discovery results and do not issue new provider requests.
- Kept product type and brand selection in the primary search panel. Supported types are Sneakers & shoes, Apparel, and Accessories.
- Catalog and retailer listings remain discovery records; a listed size or nearby store is not a guarantee of live inventory.
- Reused the existing Neon retailer cache and store-search cache; no new migration is required.
