# Outlet Radar v3.8.0 — Setup checklist

## What it adds
- A **Setup checklist** at the top of `/admin/providers` showing, in one list, what is and is not configured:
  - **Database** connection and **migrations 001 to 007** (detected from the tables and functions that exist in Neon), each with the exact file to run if it is missing.
  - **CRON_SECRET** (flagged unless it is at least 32 characters), the **provider keys** (PCKT, SerpApi, API.SH, Channel3, eBay, Impact), **affiliate templates**, **feed ingestion**, and the **site settings** (operator, contact, address).
- Items are marked **required** (red "!" when missing), **recommended** or **optional**, with a one-line hint, and a summary such as "6/6 required, 3/4 recommended".
- It reports only whether something is set, never its value: no keys, tokens, secrets or tracking links appear, so a screenshot is safe to share.

## Why
Seven migrations and about fifteen settings are easy to get partly right. The checklist replaces guessing with a list, and makes it quick to see what a problem report is missing.

## Migration and configuration
- No database migration. No new variables.

## Validation
- `npm test`: all checks pass, including 10 new ones (237 in total): migrations detected on a fully migrated database, a missing table reported with the right migration file, short secret flagged, key pairs (eBay, Impact) required together, levels correct, summary counts, no secret value ever present in the report, checklist available only behind the admin secret.
- Production build passes.
