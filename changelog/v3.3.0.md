# Outlet Radar v3.3.0 — One gender control, best price for your size across every source

## Feedback this addresses
- The Filters panel asked for the gender again (the v3.0 **Size type** dropdown duplicated the **Gender** control).
- The size price only considered StockX and GOAT, so the "best price for your size" ignored retailers.
- Other sizes were still listed on cards and in Compare offers while a size filter was active.

## Changes
- **One control.** The Size type dropdown is gone. The **Gender** dropdown decides the size scale (Men → men's US, Women → women's US, Kids → kids' Y). A marker typed in the size box still wins (`W 8`, `10.5W`, `5Y`). When Gender is "All", sizes are read as men's and the help text under the size box says so.
- **Best price across all sources.** With a size entered, each product card now lists one price row per seller that has that size, lowest price first: marketplace asks from StockX, GOAT and Flight Club (marked "✓ ask for this size") and retailers such as Nike.com, Foot Locker, Champs and other stores whose listing includes that size (marked "size listed · stock unconfirmed"). A women's-labelled size is included when it converts to your size for Nike, Jordan, New Balance and adidas, and says "converted".
- **Price filter.** Min/max price applies to the prices of sellers that have your size, from any source.
- **Only your size is shown.** While a size filter is active, cards no longer show the "Size signals" list of other sizes or the any-size headline price. In **Compare offers**, each seller shows only the selected size (its ask, or "listed by seller, stock not confirmed", or "Not listed by this seller"), and sellers are ordered with verified asks for your size first, cheapest first, then sellers that list the size, then the rest.
- Saved searches made with the v3.0–v3.2 size type still work: an explicit size type is applied to Gender when Gender was "All".

## Limits
- A marketplace ask is verified for the size; a retailer listing that includes your size is not proof the size is in stock. The card says which is which.
- Live marketplace size prices are still fetched for the first 20 results after you press **Apply refinements**, and Flight Club size detail is limited to a few products per lookup because each costs PCKT credits. Retailer rows come from the listings already in the catalog, so they appear without extra credits.
- Retailers whose listing carries no size information (many Google Shopping results) cannot appear as size-specific rows.

## Migration and configuration
- No database migration. No new variables.

## Validation
- Production build and TypeScript check pass.
- 39 unit checks for sizes (up from 29), including: one row per seller, cheapest first; other sizes never appear; headline is the cheapest verified ask; the price cap respects only sellers that have the size; marketplaces with no ask are dropped while retailers remain; women's-listed sizes convert for Nike.
- Not exercised in a real browser.
