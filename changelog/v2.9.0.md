# Outlet Radar v2.9.0 — Affiliate link templates

## What it adds
- A new optional setting, `AFFILIATE_LINK_TEMPLATES`, turns plain store links in **Compare offers** into your affiliate tracking links, with no code changes. It is a JSON object that maps a store's website host to the tracking-link template from your affiliate network's deep-link generator, with `{url}` marking where the product link goes.
- Works for any network that offers deep links (Impact, Rakuten, CJ, Awin, and others) and for any store you have joined, including StockX, GOAT, Foot Locker, Champs, adidas and so on.
- Impact and eBay Partner Network results already carry your tracking links; they are marked as affiliate links and never wrapped twice.
- Wrapping happens only as offers are sent to the browser. The cache and catalog keep the plain store URLs, so changing or removing a template takes effect immediately.
- Each wrapped offer shows a short disclosure under the link: "Affiliate link: Outlet Radar may earn a commission at no cost to you."
- Safety rules: templates must be `https://` and contain `{url}` or `{rawurl}`; invalid JSON or entries are ignored, so a typo cannot break comparisons; hosts match the store's domain and its subdomains only (look-alike domains such as `notstockx.com` do not match); non-web links are never wrapped.

## Not included
- It does not decide which programs to join. The v2.8 click report shows which stores your visitors click, which is the guide for which programs to apply to.
- Catalog browse cards have no outbound store links, so only Compare offers use this.

## Migration and configuration
- No database migration.
- New optional variable: `AFFILIATE_LINK_TEMPLATES`.

## Validation
- Production build and TypeScript check pass.
- 97 scenario checks pass against PostgreSQL with mocked providers, including URL encoding, subdomain and look-alike host handling, most-specific-host precedence, rejected templates, no double wrapping, wrapped links on fresh and cached responses, plain URLs in the cache, and immediate removal.
- Not verified against any live affiliate network: the template formats are whatever your network's deep-link generator gives you.
