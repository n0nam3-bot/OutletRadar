# Outlet Radar v3.1.0 — Saved searches with price-drop tracking

## What it adds
- **Save this search** appears with the results. It stores the whole search: words, item type, brand, audience, year, size and size type, color, price range and sale-only.
- Saved searches are listed under **Watchlist**. **Run & check prices** restores the filters, runs the search, and reports what changed since you last checked: price drops (largest first), prices that went up, and new products. Matching cards show "↓ $X since you last checked".
- The tracked price is the verified price for your selected size when there is one, otherwise the lowest listed price.
- Saved searches live in the visitor's own browser (local storage): no account, no e-mail address and nothing stored on the server. Up to 20 searches, 200 tracked products each; saving the same search again updates it.
- Running a saved search is a normal search, so repeated checks cost no extra provider credits while results are cached.

## What it does not do
- It does not send e-mail or push alerts. Because nothing is stored on the server, price changes are shown when you open a saved search. E-mail alerts need a sending service with a verified domain, consent and unsubscribe handling, and stored e-mail addresses; they are not built yet.

## Migration and configuration
- No database migration. No new variables.

## Validation
- Production build and TypeScript check pass.
- 17 unit checks for the saved-search logic: stable ids, style-code product keys, drop/rise/new detection, noise tolerance, caps, corrupt or blocked storage failing soft.
- Not exercised in a real browser.
